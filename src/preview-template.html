README.md

Quantum Core

基于分层时间轮的分布式任务调度引擎。为高并发、低延迟的任务编排提供简洁可靠的基础。

快速开始

# 安装示例 CLI
go install example.com/nebula-lab/quantum-core/cmd/qc@latest

# 启动单节点服务
qc serve --config ./config.yaml

特性

  • 四级分层时间轮，从毫秒任务到长期调度。
  • 工作池与队列分离，按负载调整并发。
  • 集群协调与故障恢复，支持任务状态追踪。
  • Web 看板与 Prometheus 指标，便于观察调度行为。

Quantum Core 集群部署指南

本指南说明如何启动一个小型调度集群，并检查任务分配、运行状态和失败重试。首次部署可以先使用两个工作节点，确认每一步正常后再增加节点。

一、准备运行环境

开始前，请准备配置文件、日志目录和节点名称。每个节点使用独立名称，便于从日志中区分任务由哪一台机器处理。服务启动后先检查健康状态，再提交少量示例任务。

项目建议配置用途
调度节点scheduler-01维护任务时间与分配信息
工作节点worker-01、worker-02并行执行已分配任务
日志目录./logs保存运行和重试记录

二、启动与检查

# 本地虚构示例命令
qc serve --config ./config.yaml
qc status --endpoint http://127.0.0.1:8080

看到节点状态为 ready 后，可以提交一批简单任务进行验证。检查任务是否按时触发、失败后是否重试，以及重启一个工作节点时其他节点能否继续处理任务。

先确认基本流程，再逐步提高任务数量。每次调整都记录配置和观察结果，便于比较。

三、上线前确认

  • 每个节点都有独立名称，且时间同步正常。
  • 运行日志能够区分成功、重试和最终失败。
  • 停止一个工作节点后，任务能够重新分配。
